## הוראות הרצה בסימולטור (לבעלים)

1. להוריד ולפתוח את `t2-simulator-packages-v2.zip`. בכל חבילה יש תיקייה `OPENFRMT/30000000.26/11241300/`, ובה `INI.TXT` ו־`BKMVDATA.TXT`.
2. לפתוח את הסימולטור הרשמי: `https://secapp.taxes.gov.il/TmbakmmsmlNew/frmCheckFiles.aspx`.
3. לכל חבילה, בסדר PRE, ‏POST, ‏STRADDLE:
   1. לבחור את סט התווים **Windows (ANSI) ISO-8859-8-I**.
   2. להעלות את `INI.TXT` ואת `BKMVDATA.TXT` של אותה חבילה.
   3. לשמור את דוח התוצאה כ־PDF בשם `simulator-report-T2-<PRE|POST|STRADDLE>-<YYYY-MM-DD>.pdf` בתיקייה הזו, ואת טקסט העמוד בקובץ `.txt` באותו שם.
4. לרשום בטבלה את מספר הקלט שהסימולטור נתן ואת התוצאה.
