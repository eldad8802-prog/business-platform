# `docs/archive/`

Documents kept for the record, not as live guidance.

A document belongs here when it was **true when written** and is still worth
reading for context, but is **not** something to act on today — a dated audit, a
readiness snapshot, or the design of a programme that has not been resumed.
Nothing here is a source of truth. If a document in this folder ever becomes
load-bearing again, move it back up into `docs/` rather than citing it from here.

Everything in this folder was salvaged on **2026-09-03** from the abandoned
`feat/corporate-marketing-warm-alignment` branch, which was 133 commits behind
`main` and whose work had otherwise already landed through other PRs. These files
existed nowhere else in version control before this commit.
