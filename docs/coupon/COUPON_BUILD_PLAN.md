## שלבי ביצוע (מאושר: A → B → C)

**שלב A — יסוד מערכת-העיצוב (additive):**
1. סט-טוקנים לזונה הצרכנית (טורקיז/כתום/סגול/ורוד) — קובץ חדש מבודד ב-`lib/design/`, לא נוגע ב-`TOKEN.warm`.
2. רכיבים חדשים: כרטיס-טיקט (ניקוב+מספריים+thema) · שורת גלילה-רוחבית · תצוגת-קופון-חיה · badge "הדגמה/בקרוב".

**שלב B — פלואו יצירה עסקי (🟢 אמיתי):** בנייה מחדש של `app/offers/create/page.tsx`: מטרה→כיוון→Builder→תוקף/תנאים→תצוגה→צור→פורסם. מטרה+כיוון = state ארעי לא-נשמר. Builder מרכיב ל-`customerBenefitText`/`title`/`description` → `createOffer` הקיים. אפס schema.

**שלב C — זונה ציבורית (demo מתויג):** מרקטפלייס (רשימה demo) · עמוד ציבורי (תצוגה על publicId, CTA "קבל קופון" מושבת) · קופון אישי (QR קיים) · מצבים (פג/מומש אמיתי, אזל demo). Feature-flag אופציונלי לכל הזונה.

**שלב D — ניהול/מימוש:** בהמשך.
